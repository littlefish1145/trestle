# Build Analyzer 里程碑

1. M1 会话、Ninja 日志增量、CLI 与 JSON。
2. M2 单动作 DAG、关键路径、并行时间线、Trace、动态依赖与 pool。
3. M3 文件影响范围和实际增量构建解释。
4. M4 隔离历史样本、稳健预测、预测误差和受限调度模拟。
5. M5 在原生 Ninja 上研究并验证实际调度接口。比较使用同一版本和脏动作集合，配对重复采样。
6. M6 显式启用的编译器深度采集适配。
7. M7 TUI、离线 HTML、基准和操作文档。

验收以 Windows 上的单元、集成和 CLI 实测为主，环境可用时扩展到其他工具链。历史实验以前置快照和 CLI 输出记录脏集合、工具版本、退出状态、执行时长。
